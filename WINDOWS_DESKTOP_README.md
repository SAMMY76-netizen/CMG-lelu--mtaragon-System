# CMG System - Windows Desktop Version

## Features
- ✅ Full Flutter Application
- ✅ Material 3 Design
- ✅ Authentication System
- ✅ Member Management
- ✅ Dashboard Analytics
- ✅ Real-time Updates (with Firebase)
- ✅ Offline Support
- ✅ Dark Mode

## System Requirements

### Minimum
- Windows 10 (Build 19041) or later
- 200 MB free disk space
- 4 GB RAM
- .NET Framework 4.5+

### Recommended
- Windows 11
- 500 MB free disk space
- 8 GB RAM

## Installation

1. Download `CMG_System_Installer.exe`
2. Double-click to run
3. Follow installation wizard
4. Launch from Start Menu or Desktop

## First Run

1. Login with test credentials:
   - Email: `admin@cmgsystem.com`
   - Password: `AdminPassword123!`

2. Or create a new account

3. Configure Firebase (optional for full features)

## Uninstallation

- Go to Control Panel → Programs → Uninstall a Program
- Find "CMG System"
- Click Uninstall

## Troubleshooting

### App won't start
- Ensure Windows 10 or later
- Install .NET Framework 4.5+
- Restart your computer

### Firebase not working
- Check internet connection
- Update `firebase_options.dart`
- See README.md for setup
